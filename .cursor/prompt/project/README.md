# NestJS 11 + Prisma + RBAC + Docker + Vue3 项目文档生成 Prompt 包

本目录整理了一套用于 Cursor Agent 生成企业级项目技术文档的 Prompt。

适用项目：

-   NestJS 11
-   TypeScript
-   Prisma ORM
-   PostgreSQL
-   Redis
-   RBAC权限系统
-   Docker
-   Vue3 + TypeScript 管理后台

目标：

让新开发人员能够快速理解： - 系统架构 - 模块职责 - 数据设计 - 权限流程 -
部署方式 - 二次开发方式

文档生成原则：

1.  基于真实代码分析
2.  禁止编造不存在功能
3.  输出 Markdown
4.  结合目录、核心文件、调用流程说明
